Estudio de usabilidad de GBSokoban

Este editor forma parte de un estudio de usabilidad sobre GBSokoban, un lenguaje específico de dominio para crear juegos del género Sokoban para la Game Boy.

Si participas, el editor guardará de forma anónima el código de tu juego cada vez que compiles, los errores que aparezcan y las ayudas que uses.

Eres el participante número

Completa las cuatro fases de la Tarea y, al terminar, rellena el Cuestionario. Apunta tu número de participante, porque es lo primero que se te pedirá. No cierres esta pestaña hasta terminar o perderás tu número de participante y tu progreso.
